Mole Rush

Set up the units. Cancel them out. Race to the answer.

Every stoichiometry problem is a chain of fractions. Each fraction cancels the unit before it, until only the unit the question asks for is left. Build the chain, watch the units cancel, and beat your best score.

Type the code your teacher or a classmate gives you, like MOLE-38. Everyone who uses the same code on the same map gets the same questions in the same order.

How to play
  • Read the problem. The balanced equation and the molar masses are always given.
  • Build the setup. Start with what you are given. Each fraction's bottom must cancel the unit on top before it. The last top must be the unit the question asks for.
  • Place tiles: tap a tile, then tap a box. You can also drag a tile into a box. Tap a filled box to move its tile, or tap its × to clear it.
  • Keyboard: Tab to a tile, Enter to pick it up, Tab or the arrow keys to a box, Enter to place it. Backspace clears a box, Esc puts a tile back.
  • Check: green boxes are right, red ones come with a hint. After two tries you can press Show me.
  • Points: 100 for a first-try answer (plus a streak bonus), 60 on the second try, 30 after that.
